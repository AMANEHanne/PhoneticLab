# 🎀 PhoneticLab

PhoneticLab is a modular speech analysis platform built with Streamlit and Parselmouth for acoustic, prosodic, and voice quality analysis of speech corpora.

## Features

- 📊 Acoustic analysis
  - Mean Pitch
  - Pitch Range
  - Pitch Variability
  - Mean Intensity

- 🎵 Prosodic analysis
  - Duration
  - Pitch Variability
  - Intensity Variability

- 🎙️ Voice quality analysis
  - Jitter
  - Shimmer
  - Harmonics-to-Noise Ratio (HNR)

- ⚙️ Advanced analysis settings
  - Pitch floor
  - Pitch ceiling
  - Time step

- 📁 Corpus-oriented workflow
  - Multiple audio upload
  - Modular analysis selection
  - CSV export
  - Project-based organization

## Technologies

- Python
- Streamlit
- Parselmouth
- Praat
- NumPy
- Pandas
